# 🚗 Tienda de Repuestos AutoShop

Sistema completo de tienda de repuestos automotrices con panel de administración integrado.

## ✨ Características

### Tienda Pública
- 📱 Diseño responsive
- 🔍 Búsqueda en tiempo real
- 🏷️ Filtrado por categorías
- 📍 Direcciones con enlace a Google Maps
- 🖼️ Tarjetas de productos con imagen, precio y ubicación

### Panel de Administración
- ➕ Agregar nuevos productos
- ✏️ Editar productos existentes
- 🗑️ Eliminar productos
- 💾 Almacenamiento local (localStorage)
- 🔄 Restaurar productos por defecto

## 🛠️ Tecnologías

- HTML5
- CSS3 (Flexbox y Grid)
- JavaScript Vanilla
- localStorage para persistencia de datos
- Google Maps API (enlaces directos)
